# 🎮 Project: PlayStation Digital Store & AI Ecosystem (PSN Vouchers)

## 1. Концепция и видение продукта
Интеллектуальный Telegram-сервис (на базе **Telegram Mini App**) по продаже **12-значных цифровых кодов пополнения (PSN Gift Cards)** для турецкого, американского и польского регионов PlayStation Store.

Сервис решает главную проблему геймеров в РФ и СНГ после 2022 года: дает возможность **покупать игры в 2 раза дешевле** официального розничного ритейла, **без передачи логина и пароля** от аккаунта, с моментальной доставкой кода в руки.

---

## 2. Ключевые столпы системы (Core Pillars)

### 🌟 Столп 1. Премиальный UI/UX (Telegram Mini App)
* **Формат:** Веб-приложение внутри Telegram (бенчмарк: *TK Store / tkstoree.ru*).
* **Визуальный стиль:** Тёмная геймерская тема, карточки игр с постерами, плавные микроанимации, витрина скидок.
* **Умные подборки:**
  * «Скидки недели в PS Store (до -85%)»
  * «Хиты с русской озвучкой»
  * «Игры до 500 ₺»
  * «Эксклюзивы PlayStation 5»
* **Интуитивная корзина:** Клиент выбирает игру или вводит сумму ➔ система автоматически формирует оптимальный пакет карт пополнения.
* **Гайд активации и обхода ошибок (DNS Fix):** Интерактивная инструкция с готовыми турецкими DNS (ControlD / статические турецкие DNS) для решения типичных ошибок Sony при активации кодов без VPN.
* **Категория цифровых подписок:** Быстрые товары-локомотивы (AI-сервисы, Spotify, Duolingo) для снятия барьера первой покупки.

---

### 🛡️ Столп 2. Авто-парсер PS Store + Детектор PS Plus (Фактор доверия)
* **Синхронизация каталога:** Бот в реальном времени отслеживает турецкий (и американский) PS Store: цены, действующие акции, появление новых скидок.
* **Киллер-фича проверки PS Plus:**
  Если игра входит в бесплатный каталог подписки *PS Plus Extra / Deluxe* (библиотека из ~1 500 игр), карточка товара выводит заметную плашку:
  > 🛑 **«Не покупай эту игру отдельно! Она доступна бесплатно в вашей подписке PS Plus Extra»**
  > *Кнопка: «Купить подписку PS Plus от ... ₽»*
* **Бизнес-эффект:** 
  1. Создает максимальную лояльность: клиент видит, что сервис заботится о его кошельке, а не пытается «втюхать» товар.
  2. Служит органическим триггером для продажи дорогих годовых подписок PS Plus.

---

### 🤖 Столп 3. Интерактивный AI-консультант («Утилизатор сдачи»)
Решает главную проблему покупки ваучерами — некратные остатки на балансе кошелька:
* **Автоподбор под остаток:**
  Если игра стоит 150 ₺, а минимальный подходящий ваучер взят на 200 ₺, бот видит остаток в 50 ₺ и предлагает:
  > *«У вас останется ровно 50 ₺! На текущей распродаже на них можно забрать: DLC к вашей игре, культовую классику (Limbo, Doom, Hotline Miami) или сохранить на балансе. Показать варианты за 50 ₺?»*
* **AI-подбор игр:** Интерактивный чат-помощник, рекомендующий игры по настроению (*«Посоветуй атмосферный хоррор на двоих»*, *«Что подарить другу в PSN»*).

---

### 📊 Столп 4. Автономный AI-маркетолог (Growth & Analytics Agent)
Внутренний автономный агент для управления конверсией и маркетингом сервиса:
* **Сквозная аналитика воронки:**
  * Заходы в Mini App ➔ Просмотры карточек ➔ Добавления в корзину ➔ Переход к оплате ➔ Успешная транзакция.
* **Анализ узких мест:** 
  * Выявление причин отказов (на каком шаге клиент закрывает приложение: испугался реквизитов, не понял инструкцию, долгий ответ).
* **Автоматический возврат клиентов (Retention):**
  * Триггерные сообщения при брошенной корзине: *«Вы смотрели Silent Hill 2. До конца скидки в PS Store осталось 24 часа. Помочь с оформлением?»*.
* **Маркетинговые рекомендации владельцу:**
  * Агент анализирует паттерны аудитории и подсказывает, где эффективнее закупать рекламу (например: *«60% аудитории берут спорт-симуляторы, рекомендую посев в паблике по FIFA»*).

## 3. Бизнес-модель с нулевым стартовым капиталом (0 ₽)

* **Модель:** Агентский дропшиппинг по 100% предоплате.
* **Оборотные средства:** Не требуются. Коды покупаются за деньги клиента сразу после подтверждения чека.
* **Закупка кодов:** Оптовые биржи цифровых товаров (Plati.market, Digiseller, FunPay, SEAGM, Turgame).
* **Юнит-экономика (расчет на заказе в 1 000 ₺):**
  * Розничная цена для клиента: ~3 100 ₽
  * Закупка кода у оптовика: ~2 350 ₽
  * Спред конвертации (RUB ➔ USDT ➔ Поставщик) + комиссии: ~220 ₽
  * **Чистая прибыль с одного чека:** **~530 ₽ (~17% чистой маржи)**.

## 4. Архитектура и стек технологий

```
               [ Пользователь в Telegram ]
                            │
               ┌────────────┴────────────┐
               ▼                         ▼
      [ Telegram Bot (FSM) ]   [ Telegram Mini App ]
      (aiogram 3.x / WebApp)   (HTML5, CSS, Vue/React)
               │                         │
               └────────────┬────────────┘
                            ▼
                   [ Backend API ] (FastAPI / Python)
                            │
     ┌──────────────────────┼──────────────────────┐
     ▼                      ▼                      ▼
[SQLite / Postgres]   [Парсер PS Store]    [AI-Консультант]
(База данных, склад,  (Цены, скидки,       (OpenAI / Gemini,
 заказы, хэши чеков)   каталог PS Plus)     утилизация сдачи)
                            │
                            ▼
              [ AI-Маркетолог & Аналитика ]
              (Воронки, брошенные корзины, отток)
```

* **Frontend:** Telegram Web App (HTML, Tailwind CSS, плавные анимации, адаптив под iOS/Android).
* **Backend:** Python 3.11+ (FastAPI / aiogram 3.x).
* **База данных:** SQLite (для MVP) ➔ Supabase / PostgreSQL (для масштабирования).
* **Алгоритм корзины:** Полный перебор комбинаций (`combinations_with_replacement`) с минимизацией итоговой цены в рублях (Unbounded Knapsack).
* **Безопасность чеков:** Хэширование файлов чеков СБП (SHA-256) для предотвращения дублей.

## 5. Дорожная карта запуска (Roadmap)

1. **Этап 1: Core & База данных**
   * Схема БД (пользователи, заказы, номиналы, буферный склад).

   * База игр из каталога PS Plus Extra/Deluxe.
3. **Этап 3: Telegram Mini App & Bot**
   * Разработка интерфейса витрины и корзины.
   * Интеграция приема оплат и подтверждения чеков.
4. **Этап 4: AI-модули**
   * Подключение ассистента «Утилизатора сдачи».
   * Дашборд AI-маркетолога для анализа конверсии.
